# Lines of Stone

A collection of ten poems by Subham Mahesh, along with the song **Kaayar Ishq Ma**.

## Contents

| File | What it is |
|------|------------|
| [`index.html`](index.html) | *Lines of Stone*, the poetry collection |
| [`song.html`](song.html) | *Kaayar Ishq Ma*, the song page with lyrics and video player |
| [`song.mp4`](song.mp4) | Song video |
| [`song-poster.jpg`](song-poster.jpg) | Poster image for the song video |

### Poems

1. Lines of Stone
2. Ravan Dahan
3. Panno Mein Kismat
4. Shayar ki Mehfil
5. Naqsh
6. Shunyata
7. Andha Mulk
8. Udaan
9. Fate
10. Kaayar

## Viewing

It's a static site, so you can open `index.html` in a browser or serve the folder with any static file server:

```bash
python3 -m http.server
```

Then visit <http://localhost:8000>.
